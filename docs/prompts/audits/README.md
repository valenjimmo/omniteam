# Dated development audits

Store post-check-in audit snapshots here as
`YYYY-MM-DD-<scope>.md`. Use `AUDIT-01` in
`../DEVELOPMENT_PROMPT_QUEUE.md` to create them and `AUDIT-02` to consolidate
durable findings into `../AUDIT_BACKLOG.md`.

Audit files record evidence at a point in time. Do not implement directly from
an unconsolidated audit when the finding conflicts with canonical governance or
duplicates an existing backlog item.
